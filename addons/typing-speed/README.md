# Typing speed

Turn on **Typing speed** in **Settings → Addons** to see estimated words and characters per minute in the status bar. The estimate resets after five seconds without typing.

The display refreshes once per second. Every typed character still contributes to the estimate between refreshes.

Only typing in the editor counts. Use **Word count** instead if you want totals for your document.
